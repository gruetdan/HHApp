<h1>Household Hub</h1>
<p>The app offers an overview over different expense lists. The main functions are:
  <li>Add new type of list / new expense list</li>
  <li>Add expense with amount [CHF], description, date, user</li>
  <li>Overview over different expense lists</li>
  <li>Summation of expenses in a list</li>
</p>
